# 可视化控制台

`index.html` 是单页可视化界面，由 FastAPI 根路径提供。不要直接双击打开文件，否则
浏览器无法访问 `/dashboard/*` 和检测 API。

该目录只用于本地开发、训练展示与答辩，不进入服务器最小运行包。

```bash
python run.py serve
```

访问 `http://127.0.0.1:8000`。页面包括：

- 数据规模、攻击类别和混淆策略总览；
- 原始/混淆/正常样本浏览及现场混淆；
- 训练、测试、验证任务的实时进度、时间线和日志；
- 最终模型指标、混淆矩阵、P99 和 WAF 对比图表；
- 实时代理请求量、攻击率、阻断数、延迟、分布图和攻击证据表格；
- 单载荷或完整 HTTP 请求的在线检测。

本地页面每 2 秒读取 `runtime/proxy_access.jsonl`。业务流量必须经过 WAD 代理入口才会
产生实时记录；生产服务器只部署在线检测 API 和代理，不上传此页面及 Dashboard 后台。

页面数据来自 `src/dashboard.py`，所有后台任务均为固定白名单命令，不接受任意 shell。
