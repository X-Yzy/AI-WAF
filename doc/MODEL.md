# 模型说明

## 最终配置

- LightGBM：38维人工与归一化特征，最多1,400轮，早停100轮。
- 文本模型：字符TF-IDF，2至5元组，`min_df=2`，
  `max_features=140000`，逻辑回归 `C=6`。
- 文本输入：`原始载荷 __normalized__ 归一化载荷`，与运行时一致。
- 融合权重：LightGBM 0.30、文本模型0.70。
- 高阈值：0.34495921；低阈值：0.05。

当前模型在 34,721 条独立测试记录上的 Precision 为 99.3259%、Recall 为
99.2079%、F1 为 99.2669%、FPR 为 0.0528%；混淆矩阵为
`[[32179,17],[20,2505]]`。训练指标以 `models/current/training_results.json` 为准，
完整链路指标以 `models/current/pipeline_evaluation.json` 为准。

## 参数选择

依次比较了16组采样/类别比例、16组字符模型、18组类型损失权重及
5组C值细化，共约55组配置。选择只使用验证集，并满足召回率不低于
0.95、FPR不高于0.001的约束，再最大化：

`0.45 × F1 + 0.35 × 攻击类型宏平均召回率 + 0.20 × 混淆攻击召回率`

C=6、7、8在验证集进入相同性能平台，因此选择复杂度更低的C=6；
C=10开始回落。额外按稀有类型加权会增加误报，因此最终不采用。
