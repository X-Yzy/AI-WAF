# 系统设计

## 目标与边界

系统面向 URL、Body、Header、Cookie 和 Path 中的 Web 攻击载荷，
重点提升对多层编码、实体化、字符串变形和组合混淆的鲁棒性。字段模型
不代替请求级上下文判断；服务器模块不训练模型。

## 检测链路

1. `parser.py` 将原始 HTTP 请求拆分为带位置和参数名的字段。
2. `normalizer.py` 迭代执行 URL、HTML实体、Unicode、Base64、
   十六进制等还原，并记录解码深度、收敛状态和熵变化。
3. `extractor.py` 按固定顺序构造38维数值特征。
4. `engine.py` 执行高置信原始与归一化规则。
5. `pipeline.py` 执行安全上下文、参数位置和参数名判断。
6. LightGBM学习结构特征，字符模型学习原始与归一化文本上下文。
7. 两模型按0.30/0.70融合，并使用元数据阈值0.34495921判定。
8. 请求级接口将多个字段结果汇总为请求结果。

## 应用职责

- 本地实验：`src.local_app`，允许生成混淆、查看归一化与特征、训练和评测。
- 服务器在线服务：`src.runtime_api`，仅加载已验证模型并提供检测、健康检查和运维只读信息。
- 实时防护：`src.proxy`，支持 monitor/block、fail-open/fail-closed和JSONL安全日志。
- 最小服务器包：`deployment/server_runtime`，明确排除数据、训练、测试、生成器和本地界面。

## 安全与可重复性

- 固定随机种子20260728。
- 抽样按原始攻击组稳定排序，避免同组变体随意拆分。
- 验证集选择模型和阈值，测试集只用于最终一次评估。
- 模型文件由SHA-256清单保护；运行包另有独立完整性清单。
- 正式模型只从 `models/current` 加载，训练默认写入 `models/candidate`。
